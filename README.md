# 👻 From The Other Side — Paranormal Sightings API

A Fullstack application for submitting and reading creepy paranormal sighting stories. Built with Node.js to practice full HTTP request handling, including **`GET`** data fetching and **`POST`** payload parsing.

---

## 🚀 Status: In Active Development 🛠

This project is currently under construction. I am implementing core server routing, request body parsing, and fullstack connection with the frontend.

---

## 🛠 Tech Stack

- **Backend:** Node.js, ES Modules (`"type": "module"`)
- **Frontend:** HTML, CSS
